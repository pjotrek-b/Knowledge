Identifying file formats/types

General Syntax:

$ file FILES

Example:

$ file *

Example: Show MIME types of *.*:

$ file --mime *.*

Fix file number sequence

Useful for film-scans 😄️

i=1                                 # start counter at 1
for FILE in *.dpx; do               # loop over all DPX files
  OUT=$(printf "reelX_%07d.dpx" $i) # Define the OUTput filename pattern
  echo "$FILE : $OUT"               # Show the new OUTput filename
  mv $FILE $OUT                     # Move (=rename) $FILE to $OUT

  i=$((i+1))                        # Increment counter +1
done

I prefer to use “symbolic links” instead of renaming the source files.

So instead of mv $FILE $OUT: ln -s $FILE $OUT.

This allows to keeping the original filename structure, while getting a “thin copy” with your changes.

Save any command output to a file?

Use > (overwrite) or >> (append)

  • General:
    $ whatever_command > OUTPUT_TO_FILE

  • Example:
    $ ls *.* > list.txt

  • Append:
    $ ls *.* >> list.txt

Create a file/folder listing:

Get path/filename/size/etc information on any file/folder branch of any digital collection.

  1. As plain text file: ls -laR > listing.txt
  2. Or: CSV spreadsheet (Comma Separated Value)

Listing as a CSV

List all entries of the current folder tree in a CSV-compatible format: (including subfolders)

$ ls -laRQ --time-style=full-iso | tr -s ' '

  • -la: detailed (long) listing of all (+hidden) entries.
  • -R: Recursive (traverse subfolders).
  • -Q: Quote entries (wrap file-/foldernames in ‘“’)
  • tr -s ' ': ‘squeeze’ double-spaces to a single one.

Markdown!

  1. Write a plain text file
  2. Format the text like ‘on an ancient typewriter’ (headline, bold, italic, etc)
  3. Save it as “.md”
  4. Then:
    pandoc text.md -o text.pdf (to convert to PDF)
Of course you need a tool which can convert from Markdown to PDF. Such as pandoc.

    URL=$(echo "$LINE" | cut -d ' ' -f 1)
    yt-dlp $URL
done < "$LIST"

Checksums / Hashcodes

  • Create (one file):
    $ md5sum FILENAME > manifest.md5

  • Create (by mask/selection):
    $ md5sum *.* > manifest.md5

  • Check by manifest:
    $ md5sum -c manifest.md5

Get all video-URLs in a YT playlist

yt-dlp --flat-playlist $YT_PLAYLIST_URL -j | \
jq -r '.url, .title'

  • yt-dlp: sophisticated video download tool (CLI)
  • --flat-playlist: Do not extract the videos of a playlist
  • -j: Quiet, but print JSON information for each url
  • jq: JSON CLI parser
  • -r: raw output (no quotes)
  • .url, .title: JSON nodes to filter/output

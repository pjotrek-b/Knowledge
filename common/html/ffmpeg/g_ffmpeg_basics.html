FFmpeg? Whatisthat?

FFmpeg is a free and open-source software project consisting of a suite of libraries and programs for handling video, audio, and other multimedia files and streams.

At its core is the command-line ffmpeg tool itself, designed for processing of video and audio files.

Source: Wikipedia: FFmpeg

Digital Video Trinity

Basic Syntax

ffmpeg -i INPUT_FILE \
-c:v ... -b:v ... [VIDEO PARAMS] \
-c:a ... -b:a ... [AUDIO PARAMS] \
[MORE PARAMETERS] \
[-f FORMAT] OUTPUT_FILE

FFmpeg, what can you do?

  • List Containers: -formats

    D. = Demuxing supported
.E = Muxing supported

  • List Codecs:

    • -codecs
    • -encoder
    • -decoder
    Codecs:
  D..... = Decoding supported
  .E.... = Encoding supported
  ..V... = Video codec
  ..A... = Audio codec
  ..S... = Subtitle codec
  ...I.. = Intra frame-only codec
  ....L. = Lossy compression
  .....S = Lossless compression

Rewrap

ffmpeg -i INPUT_FILE -c copy -map 0 OUTPUT_FILE

Example output

Explain default/common FFmpeg output.

A/V separately

  • Video ‘None’: -vn
  • Audio ‘None’: -an

Set Encoding Codec

  • Video codec: -c:v CODEC
  • Audio codec: -c:a CODEC
  • Copy A + V as-is: -c copy
    (no transcoding at all! superfast.)

Transcode

FFV1, PCM 24 bits:

ffmpeg -i INPUT_FILE \
-c:v ffv1 \
-c:a pcm_s24le \
OUTPUT_FILE

FFV1, PCM 16 bits:

ffmpeg -i INPUT_FILE \
-c:v ffv1 \
-c:a pcm_s16le \
OUTPUT_FILE

CODEC enthält bei zB uncompressed PCM auch die Bittiefe/Endianess/Signed. Fragen wer weiß was “pcm_s16le” heißt.

Hier Endianess und “Signed/Unsigned” erklären (WAV 4GB anyone? ;))

Video 1

  • Resolution: -s WIDTHxHEIGHT (eg: 720x576)
  • Aspect Ratio (DAR): -aspect X:Y
  • Framerate: -r FPS

FPS: Can also be a fraction.

NTSC anyone? e.g: 30000 / 1001

Change the “image”

  • Resize:
    ffmpeg -i INPUT_FILE -an -c:v ffv1 -vf scale=720:-1 OUTPUT_FILE

  • Display Aspect Ratio:
    ffmpeg -i INPUT_FILE -an -c:v ffv1 -aspect 4:3 OUTPUT_FILE

  • Framerate:
    ffmpeg -i INPUT_FILE -an -c:v ffv1 -r 30000/1001 OUTPUT_FILE

Video 2

Pixel color model / bit-depth:
-pix_fmt FORMAT

pix_fmt: Enthält Farbmodell, Subsampling, Farbtiefe Siehe nächste Folie.

pix_fmt? = “pixel format”

  • yuv422p = YUV 4:2:2 planar
  • yuv420p
  • –
  • yuv422p10le (10bpc)
  • yuv420p10le
  • –
  • yuva422p (+alpha channel)
  • Keep-or-die: -pix_fmt +

List: -pix_fmts

Hier Endianess erklären!

btw: “+” wurde auf meine Anfrage hin eingeführt (25.Apr.2012): http://www.ffmpeg-archive.org/Preserve-pix-fmt-regardless-of-codec-td4586546.html

Change Subsampling

ffmpeg -i INPUT_FILE -c:v ffv1 -pix_fmt yuv422p OUTPUT_FILE

(Watch out: changing sub-sampling requires re-encoding!)

Audio

  • Audiocodec: -c:a CODEC
  • Samplerate: -ar SAMPLERATE
  • Channels: -ac CHANNELS
  • Bitrate: -b:a BITRATE{k,M}
More on audio channel manipulation: https://trac.ffmpeg.org/wiki/AudioChannelManipulation

A/V separately

  • Only Image (keep encoding):
    ffmpeg -i INPUT_FILE -an -c:v copy OUTPUT_FILE

  • Only Audio (keep encoding):
    ffmpeg -i INPUT_FILE -vn -c:v copy OUTPUT_FILE

  • Only Audio (to MP3):
    ffmpeg -i INPUT_FILE -vn -c:a libmp3lame -b:a 128k out.mp3

  • Only Audio (to FLAC):
    ffmpeg -i INPUT_FILE -vn -c:a flac out.flac

Video 3

  • Bitrate: -b:v BITRATE{k,M}
  • Bitrate (min): -minrate BITRATE
  • Bitrate (max): -maxrate BITRATE
  • GOP size: -g FRAMES

Video Excerpts

  • Start position: -ss DURATION
  • Backwards: -sseof DURATION
  • Length: -t DURATION

DURATION Syntax:

  • Timecode: [-][HH:]MM:SS[.m]
  • or Seconds: [-]S[.m]

Time duration syntax: See: http://ffmpeg.org/ffmpeg-utils.html#time-duration-syntax

3 seeking options (before FFmpeg v2.1):

  • Input seeking: before “-i” Position parsed using keyframes. Fast but not 100% accurate (until v2.1)
  • Output seeking: after “-i” Very slowly. Later position = longer time to wait.
  • Combined seeking: before and after “-i” Probably obsolete: replaced by accurate “input seeking” since v2.1

Video Excerpts

  • Start Offset:
    ffmpeg -ss DURATION -i INPUT_FILE -c copy OUTPUT_FILE

  • Only Beginning:
    ffmpeg -t DURATION -i INPUT_FILE -c copy OUTPUT_FILE

  • Offset + Length:
    ffmpeg -ss DURATION -t DURATION -i INPUT_FILE -c copy OUTPUT_FILE

Transcoding II

H.264

“x264 H.264/MPEG-4 AVC encoder wrapper. […]
libx264 supports an impressive number of features, […]”

H.264

  • Codec: -c:v libx264
  • Bitrate: -b:v BITRATE{k,M}
  • CRF: -crf {0..51} ={lossless .. worst}
  • Presets: -preset:v {ultrafast,superfast,veryfast,faster,fast,medium(*),slow,slower,veryslow}
  • Fine tuning: -tune {film,animation,grain,...}

Sources/Links: FFmpeg Wiki, FFmpeg docs

“subjectively sane range is 17-28”
Preset: “medium” is default

H.264

ffmpeg -i INPUT_FILE -c:v libx264 -preset:v superfast -crf 22 -c:a aac -b:a 192k OUTPUT_FILE.mp4

ProRes

“Apple ProRes is a lossy video compression format developed by Apple Inc. for use in post-production”

  • Codec: -c:v {prores,prores_aw,prores_ks}
  • Profiles: -profile:v {proxy,lt,standard,hq,4444,4444xq}

Sources / Links: Wikipedia: Apple ProRes, FFmpeg docs, Kieran Kunya’s Blog, FinalCut docs

ProRes

ffmpeg -i INPUT_FILE \
-an \
-c:v prores_ks \
-profile:v hq \
OUTPUT_FILE.mov
Mal das “:v” bei “-profile” weglassen und schauen was passiert.

FFV1

FFV1 (“FF video codec 1”) is a lossless-only video codec.

  • Codec: -c:v ffv1
  • Version: -level {1,3}
  • Coder: -coder {0=golomb,1=range}
  • Context: -context {0=small,1=large}
  • Slices: -slices {4,6,9,12,16,24,..}
  • CRC: -slicecrc {0,1}

Sources: ffv1.info

FFV1

ffmpeg -i INPUT_FILE -an -c:v ffv1 \
-level 3 \
-slices 24 \
-slicecrc 1 \
OUTPUT_FILE

From Video to Images + WAV

ffmpeg -i input.mp4 \
-an out/FRAME_%04d.png \
-vn -c:a pcm_s16le out/AUDIO.wav

From Images (+Audio) to Video

ffmpeg -r $FPS -start_number $FRAMENO \
-i reel/FRAME_%04d.png -i reel/AUDIO.wav \
-c:v libx264 -crf 22 \
-c:a aac -b:a 128k \
OUTPUT.mkv
